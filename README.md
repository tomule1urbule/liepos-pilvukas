# Liepos pilvukas

Tėvelių pagalbininkė, padedanti taisyklingai ir sveikai primaitinti mažylius: kada ir kaip pradėti, nuo kada galima kiekvienas produktas, ragavimo sekimas ir receptai.

**Atidaryti:** https://tomule1urbule.github.io/liepos-pilvukas/

## Įdiegimas į telefoną
- **iPhone (Safari):** Bendrinti → „Įtraukti į pradžios ekraną“.
- **Android (Chrome):** meniu ⋮ → „Įdiegti programą“.

Programėlė veikia ir be interneto. Visi duomenys saugomi tik telefone. Juos galima išsaugoti ir atkurti iš atsarginės kopijos (Daugiau → Duomenys).

Informacija yra bendro pobūdžio ir nepakeičia gydytojo konsultacijos. Šaltiniai pateikti programėlėje (Daugiau → Žinynas → Šaltiniai).
